New — insert after slide 2 (Background)

Related Work & Novelty

  • TREAD (Krause et al., 2025) — token routing for efficient DiT training. Presented purely as an efficiency method; the stochastic-depth training it induces is never analysed.
  • Generative Uncertainty in Diffusion (Jazbec et al., 2025) — Bayesian UQ via last-layer Laplace, for U-Net / flow matching. No DiT, no per-timestep profile; aleatoric uncertainty explicitly left as future work.
  • HyperDM (Chan et al., NeurIPS 2024) — epistemic + aleatoric via a hyper-network ensemble. Rigorous but computationally heavy; no timestep-resolved analysis.
  • Timestep-Aware Block Masking (2025) — different DiT blocks activate at different timesteps, supporting the early-vs-late hypothesis.
  • Attention entropy — an established UQ proxy in NLP and ViTs, never applied to the diffusion timestep axis.
Our gap

TREAD presents routing as an efficiency mechanism. We are the first to use its routing as an inference-time uncertainty-quantification substrate — combined with attention entropy, resolved per timestep, decomposed into epistemic / aleatoric, and linked to generation quality. Training-free throughout.

New — insert after slide 3 (Goal & Objectives)

Method — the three proxies

All three are inference-time and training-free. Dθ is the x̂0-prediction.

1 · Ensemble variance — vary the seed

Uens(t, c) = Vark [ Dθ(xt(k), t, c) ],   z(1..K) ~ N(0, I) through the full path

Captures data stochasticity — different noise, different image.

2 · Routing variance — vary the sub-network, seed fixed

Uroute(t, c) = Varm [ Dθr(m)(xt, t, c) | z ],   M = 16 random TREAD routes

Captures model / sub-network ambiguity — the only epistemic proxy.

3 · Attention entropy — single pass

Uattn(t, ℓ) = −∑ij Aij(ℓ) log Aij(ℓ)

We report the mean per-query entropy — bounded by ln N = ln 256 = 5.55, which gives the curve an interpretable ceiling (on the ceiling = attention is uniform = the block selects nothing).

Decomposition — law of total variance

Uepi = Varr[ D | z ],    Uale = Er[ Varz[ D ] ]

Seeds alone cannot separate model ambiguity from data stochasticity. Routes + seeds can — that is the whole point of having two independent noise sources.

New — critical. The deck promises 3 proxies and shows 2

Routing variance — the proxy we could not compute

Uroute(t, c) = Varm [ Dθr(m)(xt, t, c) | z ]
  • It is the only epistemic proxy. The proposal calls it “the linchpin” — the epistemic / aleatoric split in Tasks 3 and 5 is unjustified without it.
  • It is only legitimate on a TREAD-trained model: routing variance means something because the network was trained as a distribution over sub-networks. Injecting routes — or MC-Dropout — into a vanilla DiT that never saw them in training yields uninterpretable variance. The proposal says this explicitly.
Blocker

There is no publicly released TREAD DiT-XL/2 checkpoint. We cannot run it, and we cannot substitute vanilla DiT.

  • What is ready: a model-agnostic reference implementation — routing_variance, route_sanity, epi_ale_decomposition — validated on a small TREAD-trained DiT. Swapping in a real checkpoint is a one-function change.
  • Decision needed from the curator: obtain a TREAD checkpoint, or train a TREAD DiT-B/2 ourselves? This gates Tasks 2, 3 and 5.

New — the strongest result you have, currently nowhere

Key finding — both hypotheses fail, in the same direction

(a) Uens rises along the denoising path

The proposal predicts early steps (high σ) = mode selection = high seed variance, decaying late. Measured: it starts at ≈0.03–0.05, dips further around t ≈ 900, then grows monotonically to ≈0.50–0.65 at t → 0. Reproduced independently by two team members on separate code.

Why: at high σ the model resolves nothing and predicts x̂0 ≈ the conditional mean — “the average lemon” — so all seeds agree. By the end each seed has committed to its own lemon, so they disagree maximally.

(b) Uens anti-correlates with class difficulty

What it means

Vark[x̂0] in VAE latent space is dominated by how much the class’s dominant low-frequency layout swings, not by semantic ambiguity. A lemon is one big saturated blob — seeds disagree about its position, size and count, which moves a lot of latent mass. A restaurant or a coral reef is generic clutter in every sample, so per patch the seeds agree more.

Normalising each class curve by its own late value shrinks the effect (−0.62 → −0.48) but does not remove it — so it is not merely a contrast scale factor. The shape is genuinely class-dependent.

Consequences

1. Raw latent Var[x̂0] is not a valid cross-class uncertainty proxy — fine along the timestep axis within one class, but between classes it measures image statistics.  2. This makes Uroute more necessary, not less: the epistemic proxy is the only one that could isolate model ambiguity from image statistics.  3. Task 5 will be confounded unless the proxy is normalised or moved into a semantic space (CLIP / DINO embeddings of decoded x̂0).

Honest caveat

Our difficulty tiers are semantic hand-labels, and they are confounded with “clutter”. To claim anti-correlation with difficulty proper we need per-class FID — which does require real ImageNet reference images. That is the one place in this project where the dataset is genuinely needed.

Attention entropy — across all 50 classes

Block 0 sits pinned on the ceiling. That is the point of the slide, and the current version does not say it: entropy at the maximum means attention is uniform — the early block is not selecting anything, it passes everything through. Selection emerges with depth: blocks 14 and 27 fall to ≈3.4 nats as the image resolves.

So the early-vs-late structure the project is about shows up along the block axis as clearly as along the timestep axis.

This does not replace slide 5. That slide shows one class in detail; this one shows the same three blocks averaged over 50 classes with the ceiling drawn, which is what lets you claim the behaviour is general rather than a property of lemons.
